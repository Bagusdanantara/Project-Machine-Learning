# Project-Machine-Learning
Prediksi Pendapatan Penjualan Bulanan Toko
Proyek machine learning ini bertujuan untuk memprediksi pendapatan penjualan bulanan (Monthly Sales Revenue) sebuah toko di California berdasarkan berbagai faktor operasional dan demografis.

# Deskripsi Proyek
Model ini dibangun untuk membantu dalam pengambilan keputusan bisnis dengan memberikan estimasi pendapatan di masa depan. Proyek ini mencakup analisis data, pembersihan data, pelatihan beberapa model regresi, dan evaluasi untuk menemukan model dengan performa terbaik.
